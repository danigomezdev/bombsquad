# LessPartyWindow

A mod that takes the default party window of the game and rebuilds it with the same in-game style, adding global chat, private chats, friends, word censoring, translations, and much more.

## Features

### Account

- Lux account: sign in or create an account from the party window, with terms of use and privacy policy linked on the login screen
- Manage account
  - Change your name, nickname, description, or password
  - Change your character color and highlight
  - Manage active sessions
  - Delete your account
- Log out at any time

### Direct Messages (DM)

- Global chat: meet and chat with people from all over the world to play together
  - Mute the chat if you want (notifications come disabled by default)
  - Get notifications to stay active
  - Mute or permanently block people
  - Report players for several reasons: toxicity, spam, abuse, etc.
  - View the account of the people talking in the global chat, send them a friend request, and view their BombSquad v2 account
  - Translate their messages to your language, whichever you pick in the translation settings inside the mod
- Private chats: add anyone who has the mod and talk with them without anyone seeing it
  - Invite them to play
  - Send them images, mods, and game replays
  - Is your friend being annoying? No problem, block them for a few minutes
- Notifications
  - In settings you can choose the type of notification you want to receive, both for DMs and matches
  - Coming soon: custom sounds

### Social

- Search accounts by name and open their profile
- Profile search: view play time, trophies, linked accounts, current rank...
- Add players from the current match as friends to find them easily later
- Friends search: see which server your friends are in and join them directly
- Block players from the current match
- Set custom nicknames for friends or known players
- Filter party: choose whose messages you want to see (friends, people with a nickname, etc.)
- Word censoring: enable the filter to hide vulgar or toxic words in DMs or any party (available in multiple languages)
- See the server IP and port while you are connected to one
- See the full profile of a person when they send messages
- See the servers and gather list while in a match, without having to leave it to join another one

### Servers

- Server filter
  - Block servers from the list
  - See who is on a server without joining it
  - Create server shortcuts
- Player search
  - Search for people you have blocked or your friends inside our search engine and know where they are playing
  - History of the servers you played recently, and servers added to favorites
  - When you join a match you get a player monitor that tells you instantly who joins, whether it is anyone, a friend, has a nickname, or is blocked
  - Messages sent on the server are shown in a server logs window
  - See the messages a person you found in a match have sent over time, knowing which servers they played in, when they last played, and their BombSquad profile, etc.
- Server manager
  - Are you an ADMIN or moderator of a BombSquad server? Manage your servers easily with our configurable server manager
    - List the players of the server
    - Get their account ID, client ID, v2 name, PB, etc.
    - Create commands and use them with an easy user interface applied to the player you select

### Replays - Camera

- Auto-replays: they come disabled by default, enable them in the mod settings
- In a match, the options menu gives you the option to save a replay instantly and name it whatever you want
- Remember to download an auto-saved replay as soon as possible: if it exceeds the max limit of replays, the oldest ones start being replaced to make room for new ones
- Camera: you can also move the camera to any position you want and save specific positions to use whenever you want inside a match
- You can enable or disable camera persistence, so when you close and open the game it sets the last configured camera
- Coming soon in future updates: a way to take small clips from a match, as far as the game engine allows it

### Preferences

- Language support
  - Spanish, English, Portuguese, Russian, Hindi, Malayalam, Indonesian
- Colors
  - You can pick any color you want and every mod window gets configured from it, with a palette calculated from that color, or you can create your own palette with a color for each thing
- Settings
  - Configure the mod however you want
  - Enable or disable buttons if you feel you don't want some of the mod features
  - Support for SMALL, MEDIUM, and LARGE scales
  - Reset settings to default
  - And many more things
- Updates
  - Enable or disable auto-updates to update the mod manually or automatically when new updates come out. This option is enabled by default
  - Changelog: check it every time there is an update to keep up with what new features were included

### Auto-Kicker

- Automatically kick players who repeatedly rejoin after being kicked, helping prevent them from avoiding moderation by leaving the match.

### Player Stats

- `/ping all`: check the ping of all players using a customizable command.
- View kills, scores, and other available match statistics on supported servers running updated versions of BombSquad.

### BS Remote (Experimental)

- Experimental integration of BS Remote, configurable in the mod settings under the **Developers** section.
- Customize in-game music, randomize maps, change map colors, and more.
