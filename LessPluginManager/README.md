# LessPluginManager

An enhanced plugin manager for BombSquad that extends the built-in plugin window with additional functionality.

## Features

### Update System
- Detects mods that support the `UpdateWindow` class and adds an **Update** button next to the Settings button
- Opens a version checker that compares the local version with the online repository
- One-click download and replacement of updated mod files

### Mod Downloads
- Browse mods from the online store directly within BombSquad
- Filter by category: All, Mods, Minigames
- Shows which mods are already installed
- Download and install mods with a single click

### Plugin List
- Preserves the original plugin enable/disable functionality
- Adds update detection caching for fast loading
- Seamless integration with the existing plugin window
